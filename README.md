# World Champions Football 2026

A lightweight browser football game prototype built as a single HTML file.

## Run locally

Open `index.html` in a browser.

## Controls

- Player 1: WASD to move, V pass, B shoot, C switch, T tackle
- Player 2: Arrow keys to move, K pass, L shoot, N switch, M tackle

## Notes

This is a simple offline project intended for manual hosting or GitHub Pages deployment.
